# Evidence

This folder is part of the hand-in. It holds the evidence of the perception experiment in Task 4 and the photo of the hand sketch in Task 0. The lecturer checks the sheets, the time stamps and the collector IDs against `experiment_answers.csv`.

This repository is public, so everything here must be anonymous:

- A sheet never shows the name or the face of a respondent. We record a respondent only as a code, for example `R01`.
- Each photo keeps its original time stamp. Turn off the location in the camera app before you take the photo, so that the photo does not carry GPS data.
- The file name shows the collector and the respondent, for example `sheet_<collector>_R01.jpg`. A form export keeps its time stamp column.
- The sketch for Task 0 is `sketch_task0.jpg`.
- The respondents coded `sim-R01` and so on are simulated, so they have no sheet here. Every collected respondent needs a sheet or a form export.
